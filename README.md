# The IoT Academy (TIA) - Career & Placement Portal

A modern, responsive web application for The IoT Academy's career and placement transitions, showcasing alumni reviews, hiring partners, salary hikes, and educational programs.

## 🚀 Features

- **Dynamic Hero Section**: Engaging introduction highlighting student success and achievements.
- **Key Metrics & Statistics**: Visual representation of placement records, salary hikes, and hiring statistics.
- **Hiring Partners Carousel**: Showcase of top tier partner companies (TCS, Accenture, Reliance, etc.).
- **Alumni Reviews & Testimonials**: Verified LinkedIn testimonials and student success stories.
- **Modern Responsive Design**: Fully responsive across mobile, tablet, and desktop screens with sleek animations.

Open `index.html` in any modern web browser or run with a local server like Live Server.
